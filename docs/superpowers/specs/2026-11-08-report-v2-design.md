# Отчёт v2: тёмный стиль, вкладки, фэнтези-очки, итоги линий

Одобрено владельцем в чате 2026-11-08 (макет «A — тёмный киберспорт»).

## Зачем
Отчёт должен быть приятнее и понятнее: оценка игроков «как в Доте», кто выиграл линию, откуда шло золото по времени, процент хедшотов на виду.

## Что делаем
1. **Стиль A**: тёмная тема по умолчанию (переключатель на светлую), крупные числа, плашки с полосками, цвета команд Amber (янтарный) / Sapphire (синий), портреты героев в карточках и таблицах (картинки из файлов игры, кладутся в репозиторий `web/img/heroes/<heroId>.png`).
2. **Вкладки** (с адресом `#overview` и т.п., чтобы можно было скинуть ссылку на вкладку):
   - Обзор — счёт, победитель, MVP, рейтинг 12 игроков с оценками S/A/B/C/D и фэнтези-очками (по наведению — разбивка), бейджи итога линии, ключевые объекты.
   - Игроки — таблица + графики по игрокам (как сейчас: включение линий, подсказка), карточка игрока.
   - Золото — «Получено золота», GPM, график нетворса **по источникам во времени** (слоёный) для выбранного игрока, сравнение двух игроков бок о бок.
   - Бои — хронология убийств, матрица урона, объекты, карта смертей, точность.
   - Чат.
3. **Карточка игрока**: плашки У/С/П, нетворс, GPM, хедшоты от попаданий (с полоской и средним по матчу), точность, оценка + очки, итог линии; график % хедшотов во времени; билд, способности, смерти, урон кому/от кого.
4. **Фэнтези-очки** (считаются в конвейере, коэффициенты в одном конфиге):
   - убийство +0,3; ассист +0,15; смерти: max(0, 3 − 0,3·смерти);
   - добивание и денай +0,003 каждое; GPM ×0,002;
   - урон по героям +0,05 за 1000; лечение союзников (heroHealing без self) +0,05 за 1000; урон по объектам +0,1 за 1000;
   - участие в убийствах (У+П)/убийства команды × 3;
   - мидбосс, взятый командой: +1 каждому её игроку;
   - линия: выиграна +2, проиграна −1.
5. **Итог линии**: на 10:00 (снимок ≤ 600 с игрового времени, ближайший) сумма нетворса пары игроков команды на линии (`assignedLane`) против пары соперников на той же линии: > +15% — «Выиграл», < −15% — «Проиграл», иначе «Ровно». Если на линии не по 2 игрока — сравнение сумм всё равно, по факту.
6. **Оценка** по месту в матче по фэнтези-очкам: 1-е место = MVP; S — топ-2, A — места 3–4, B — 5–7, C — 8–10, D — 11–12. (Решение исполнителя, можно поменять.)
7. **Данные по времени**: разбивка золота по источникам и хедшоты по времени — из `postmatch` `players[].stats[]` (отметки ~3/6/9/12/15/20/25/30 мин + конец); общий нетворс — каждые 30 с (уже есть).

## Не делаем
- Рейтинги между матчами, профили игроков.
- Поиск более частой разбивки золота в записи (отдельная исследовательская задача).

## Совместимость
Старые матчи на сервере (без новых полей) должны открываться: страница показывает новые блоки только если данные есть; плюс скрипт `tools/reprocess.py` пересчитывает `match.json` из `postmatch_raw.json`… но снимки ents не сохраняются → для пересчёта старых матчей достаточно, чтобы новые поля строились из `postmatch_raw.json` + уже сохранённого `match.json` (playerTimeline есть). Решение исполнителя: новые поля считаются функцией от `match.json` + `postmatch_raw.json`, и сервер при отдаче досчитывает их, если отсутствуют.

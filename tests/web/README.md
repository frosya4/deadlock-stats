# Проверка Task 4

Запуск из этой папки: `npm ci`, `npx playwright install chromium`, `npm test`.
Python должен иметь зависимости из `app/requirements.txt` и сгенерированные `app/proto/`.
Порт 8765 должен быть свободен. Сервер создаёт временный DATA_DIR, прогоняет
реальный pipeline на fixtures, добавляет копию с XSS-именем и запускает uvicorn.
Только dldump заменён скриптом копирования распакованных fixtures.
Скриншоты сохраняются в `screenshots/`. Загрузка CDN нужна для uPlot.

## Решения по области работы

- Реализуется только Task 4 в указанном общем checkout; app/ и parser/ не меняются.
- Отдельные worktree и агенты не создаются: это уже задача implementation sub-agent.
- goldTimeline содержит накопленные снимки: их нельзя повторно суммировать по времени.
- GPM по времени — средний доход с начала матча: нетворс / прошедшие минуты.
- Для графика золота используются те же выбранные игроки, что и для основного графика.
- Мини-карта сохраняет систему координат прототипа, без выдуманного изображения карты.
- Заданные URL cdnjs для uPlot 1.6.31 вернули HTTP 404 (проверено curl и Chromium).
  Они сохранены как основной источник; при отказе загружается та же версия с jsDelivr.

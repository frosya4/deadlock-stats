# Deadlock Stats

Deadlock Stats превращает загруженную демку `.dem` в интерактивный отчёт о матче. В отчёте есть графики нетворса и GPM по игрокам с переключателями и подсказками при наведении, источники золота, билды, карта смертей, матрица урона, лента убийств и игровой чат.

## Как это работает

Демку разбирает парсер на Rust haste с патчем проекта в `prototype/haste-patch`. Затем конвейер на Python декодирует данные `PostMatchDetails` и сохраняет готовый отчёт.

## Установка на Ubuntu

На чистом Ubuntu выполните:

```bash
git clone <repo> && cd deadlock-stats && sudo bash deploy/install.sh
```

Установщик настроит сервис и напечатает адрес вида `https://<ip>.sslip.io`. Владелец делится ссылкой на свой экземпляр лично; публичной ссылки здесь нет.

Обновление установленного экземпляра:

```bash
sudo bash deploy/update.sh
```

## Хранение и ограничения

Данные матчей находятся в `data/matches/<match_id>/`. Удаление папки матча удаляет отчёт. Исходные демки после обработки не хранятся. Размер загрузки ограничен 600 МБ, одновременно обрабатывается одна демка.

Можно также ввести номер матча для скачивания записи Valve. API загрузки: `POST /api/upload` с телом `application/octet-stream`; скачивания: `POST /api/fetch` с JSON `{"matchId":"133162474"}`. Статус задачи доступен по `/api/jobs/<job>`.

Загрузки сверяются с официальными метаданными Valve: ID, длительность, победитель и набор аккаунтов. При несовпадении или недоступности проверки отчёт получает ID `u<12 символов SHA-256>` и отметку «не проверено». Он не заменяет проверенный матч. Задания истекают через час после завершения. При рестарте очередь теряется, временные файлы очищаются.

Переменные окружения приложения (добавляйте в `app.environment` Compose):

| Переменная | По умолчанию | Ограничение |
|---|---:|---|
| `MAX_QUEUE` | 5 | Очередь вместе с резервами загрузок |
| `MAX_INFLIGHT_UPLOADS` | 2 | Одновременные загрузки |
| `MIN_FREE_GB` | 10 | Минимум свободного места для приёма |
| `MAX_STORAGE_GB` | 20 | Бюджет готовых отчётов |
| `MAX_UPLOAD_MB` | 600 | Размер демки, включая распакованную |
| `PARSE_MEM_MB` | 2048 | RLIMIT_AS каждого процесса на Linux |
| `PARSE_CPU_S` | 240 | CPU-секунды каждого процесса |
| `PARSE_TIMEOUT_S` | 240 | Общий дедлайн dldump и Python-конвейера |
| `MAX_RAW_MB` | 1024 | Суммарный вывод этапа разбора |

Compose ограничивает весь контейнер приложения: 3 ГБ памяти, 2 CPU, 64 PID. Скачивание ограничено 300 МБ сжатых данных и 240 секундами; поддерживаются bzip2 и Zstandard (Valve использует оба под расширением `.bz2`). Временные файлы удаляются также при ошибке и отмене.

## После обновления игры

Чтобы обновить имена героев и предметов, на компьютере с установленной Deadlock извлеките и декомпилируйте `heroes.vdata_c` и `abilities.vdata_c` с помощью Source2Viewer-CLI (ValveResourceFormat), затем запустите:

```bash
python tools/build_refs.py --scripts-dir <каталог-с-декомпилированными-vdata>
```

При поломке разбора после патча игры обновите патч haste в `prototype/haste-patch`.

Вход через Steam открывает публичный профиль с последними матчами и позволяет отправлять записи на обработку: не более 2 новых обработок в час на аккаунт (`PER_ACCOUNT_FETCH_PER_HOUR`). Просмотр профилей и готовых отчётов, а также загрузка собственного `.dem` доступны без входа. Для Steam OpenID задайте `PUBLIC_URL` равным публичному HTTPS-адресу сайта; в Docker Compose он формируется как `https://${SITE_HOST}`. Секрет сессии сохраняется в каталоге данных и не должен попадать в репозиторий.
